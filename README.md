# 🌡️ Temperature Converter (Java)

A simple and efficient Java console application that converts temperatures between Celsius and Fahrenheit.

## 📌 Features

* Convert Celsius to Fahrenheit
* Convert Fahrenheit to Celsius
* User-friendly console interaction
* Input validation for unit selection

## 🛠️ Technologies Used

* Java
* Standard Input/Output (Scanner)

## 🚀 Getting Started

### Prerequisites

* Java Development Kit (JDK) installed

### How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/temperature-converter-java.git
   ```

2. Navigate to the project directory:

   ```bash
   cd temperature-converter-java
   ```

3. Compile the program:

   ```bash
   javac TemperatureConverter.java
   ```

4. Run the program:

   ```bash
   java TemperatureConverter
   ```

## 💡 Usage

* Enter a numeric temperature value
* Specify the unit:

  * `C` for Celsius
  * `F` for Fahrenheit
* The program will display the converted temperature

## 🧮 Conversion Formula

* Celsius to Fahrenheit:

  ```
  (C × 9/5) + 32
  ```

* Fahrenheit to Celsius:

  ```
  (F − 32) × 5/9
  ```

## ⚠️ Error Handling

* Displays an error message for invalid unit input
